# Климат Про — монтаж кондиционеров и вентиляции (демо)

Статический одностраничный лендинг: один `index.html` с встроенными CSS и JS, без фреймворков и внешних шрифтов.
Выдуманный бренд, название, цены и отзывы — для примера. Политика персональных данных внизу страницы — заглушка.

## Что где
| Файл | Что это |
|---|---|
| `index.html` | страница, стили, форма, `<title>`, description, OG-теги |
| `favicon.svg` | иконка (тот же знак, что в шапке) |
| `og.jpg` | баннер 1200×630 для превью ссылки (кадр первого экрана) |

## Форма
Демо: заявка никуда не отправляется. После отправки показывается пример сообщения менеджеру и текст «Спасибо, перезвоним в течение 15 минут». Чекбокс согласия обязателен и не отмечен по умолчанию.

## Проверка локально
```
python3 -m http.server 8000     # открыть http://127.0.0.1:8000/
```
